# Mac test fleet: legal scope and takedown policy

The fleet (see [fleet.md](fleet.md)) is built so that nobody who runs, joins or
hosts it handles material from any game, gets around any copy protection, or
gives anyone a reason to ask for the repository to be taken down. This page
sets out the rules, the reasons for them, and what happens if a rights holder
gets in touch.

This is general information, not legal advice. Every contributor is
responsible for following the law where they live.

## The rules

Everyone who joins the fleet agrees to these. Workers accept them with
`tools/fleet/fleet.sh accept`.

1. **The fleet only tests this project's own open-source code.** A task runs the repository's test suites, which use synthetic test data generated by our own code. It never needs, and never uses, a game.
2. **No game material, ever.** Do not post, attach, link, upload or describe how to get any game's files: executables, data, assets, shaders, audio, video, saves, screenshots, captures, logs from running a game, dumps or keys. This applies to issues, comments, pull requests and results.
3. **No circumvention.** The fleet never asks anyone to get around encryption or any other technological protection measure. Do not post instructions, tools or links for doing so.
4. **No redistribution of Apple's Game Porting Toolkit.** Each person downloads it from Apple and accepts Apple's terms themselves.
5. **No implied endorsement.** The fleet is not affiliated with or endorsed by any game publisher, console maker or Apple. Don't use their logos or artwork, and don't suggest that it is.
6. **Results are data only.** Only `tools/fleet/fleet.sh` posts results, and the queue removes anything that does not match the result schema.

## Why the fleet is limited to this

### Australian law

The project's maintainers follow Australian law strictly. The fleet is
designed around the *Copyright Act 1968* (Cth):

- **Copying and communicating works** (Part III, Part IV). Game files, assets and screenshots are copyright works. Posting or hosting them would infringe, and none of the exceptions covers it. The fleet never handles them.
- **Technological protection measures** (Part V, Division 2A, ss 116AK–116AQ, and the offences in Part V, Division 5). Getting around an access-control measure, or supplying a device or service that does, is prohibited unless an exception applies. Console games are encrypted, and it is untested whether the interoperability exception covers running a whole console game on another platform. The fleet therefore never asks for, uses or describes a game dump, and this repository contains no decryption code or keys.
- **Interoperability** (s 47D). Making copies of a program that are reasonably needed to make independent software work with it is allowed, within limits. Under s 47H, a contract term that tries to exclude this has no effect. This is part of why working on the project's own code is lawful. The fleet still stays clear of the game itself.
- **Authorisation** (s 36, s 101). Someone who authorises another person's infringement can be liable too. The fleet never hands out work that needs a game, so it authorises nothing of that kind.

It also respects the *Trade Marks Act 1995* (Cth) and the Australian Consumer
Law (*Competition and Consumer Act 2010* (Cth), Schedule 2, ss 18 and 29).
Third-party names appear only to describe compatibility. The fleet uses no
logos or artwork and claims no affiliation.

### Hosting on GitHub

GitHub is a United States service. It handles copyright notices under the
DMCA notice-and-takedown process (17 U.S.C. § 512). Claims about getting
around protection measures are made under § 1201. GitHub has said that it
reviews circumvention claims with extra care before it acts on them. The
fleet is built so that neither kind of claim would have a basis:

- The fleet's files are plain-text scripts and documents written for this project. The repository's asset policy (`cargo xtask policy`, [asset-policy.md](asset-policy.md)) checks every commit.
- Fleet results are checked against a strict schema. Free text, links and file contents cannot pass.
- The queue deletes links to file-sharing sites and torrents posted in fleet issues. It hides anything that looks like game material, dumps, decryption or image attachments until a maintainer has reviewed it. Maintainers can turn the same screening on for every issue in the repository by setting the repository variable `FLEET_MODERATE_ALL` to `true`.
- No task, page or script tells anyone how to get or decrypt a game.
- The fleet's docs do not name or show any game.

## For rights holders

If you believe something here infringes your rights, please contact the
maintainers first. We aim to act within 48 hours.

- **Privately:** use *Security → Report a vulnerability* on this repository, which opens a private report that only maintainers can see. Say that it is a rights-holder request.
- **Publicly:** open an issue titled "Rights holder request" and leave out the material itself.

Give the location (a link to the file, issue or comment) and the work it
concerns. We remove material that breaks these rules without waiting for a
formal notice. If it was committed, we also rewrite git history, as
[asset-policy.md](asset-policy.md) requires.

## If a formal notice arrives

- We follow GitHub's process and take down anything that breaks these rules.
- If a notice is mistaken, for example if it targets our own code, which contains no game material and no circumvention, we may file a counter-notice through GitHub's process.
- We never re-upload removed material, and we never use mirrors to get around a takedown.

## Maintainer checklist

- Review issues labelled `fleet:review` promptly. Delete anything that breaks the rules, and delete edited-out revisions from issue edit histories.
- Open tasks only with `tools/fleet/maintainer.sh tasks`, which writes a body that passes moderation.
- Turn on private vulnerability reporting (*Settings → Code security*) so that the private contact route above works.
- Keep this page in step with the code. Changing it makes every worker accept the rules again.
